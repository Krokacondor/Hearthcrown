# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An empty but correctly shaped Hearthcrown project. It runs in the browser, draws a grid on a canvas that fits desktop and landscape-phone screens, has a tested seeded RNG and a minimal sim state, exposes the dev-only `window.__hearthcrown` hook, and has `PRODUCT.md` and `DESIGN.md` from Impeccable.

**Architecture:** `src/sim/` holds pure logic (RNG, world, game commands) with no DOM. `src/render/` draws the canvas from palette constants that mirror `DESIGN.md`. `src/main.ts` wires the page, and `src/debug.ts` installs the debug hook only in dev builds through a dynamic import, so it is stripped from production.

**Tech Stack:** TypeScript (strict), Vite, Vitest, plain Canvas 2D, Node 24 / npm 9. No engine, no UI framework.

**Spec:** `PLAN.md` (sections 2, 5.1, 6 row M0, 7) and `CLAUDE.md` (code rules, browser checks, Impeccable).

## Global Constraints

- TypeScript `strict: true`. Vite for dev and build. Vitest for tests. Plain Canvas 2D.
- `src/sim/` never imports `render/` or `ui/`, never touches the DOM, never calls `Math.random()`.
- `render/` and `ui/` read sim state and call sim commands. They never change state directly.
- Tunable numbers and content go in `src/data/*.json`.
- Targets desktop browsers **and phones in landscape**. The keyboard alone must be able to play. Every focusable element has a visible focus state (PLAN.md 5.1).
- Debug hook `window.__hearthcrown` exists **in dev builds only**, with `getState()` and `cmd(name, args)`.
- Names, art and text are original.
- Work on branch `m0-scaffold`. Small commits, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not push without asking.

## Review Focus

1. **Seed edge cases** (0, negative, huge, fractional, NaN): the RNG stays deterministic and never yields NaN. Invalid seeds throw. Tests in Task 1.
2. **`getState()` must be read-only**: mutating the returned object must not change the game. Test in Task 3.
3. **Unknown or malformed `cmd()` calls** (bad name, missing/invalid args) return `{ ok: false, error }` and never throw or change state. Tests in Task 3.
4. **Production build leaks the debug hook**: `npm run build` output must not contain `__hearthcrown`. Verification step in Task 5.
5. **Resize, rotation and high-DPI screens**: the canvas keeps its backing size equal to CSS size × devicePixelRatio, never 0 or NaN, and redraws on resize. `computeCanvasSize` tests in Task 5, phone-landscape screenshot in Task 6.

- [ ] **Step 4: Implement `src/sim/rng.ts`**

  Seed normalization: reject non-finite with `RangeError`, then `Math.trunc(seed) >>> 0`. Algorithm is mulberry32 (one uint32 of state):
  ```ts
  let t = (state = (state + 0x6d2b79f5) >>> 0);
  t = Math.imul(t ^ (t >>> 15), t | 1);
  t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  ```
  `int(min, max)` = `min + Math.floor(next() * (max - min + 1))`.

  export interface World {
    seed: number;
    day: number;          // starts at 1
    time: number;         // minutes since midnight; starts at 360 (06:00)
    gold: number;
    reputation: number;   // -100 (Feared) .. +100 (Loved), starts 0

    citizens: unknown[];  // typed in M3

  // src/sim/game.ts
  export interface Snapshot {
    seed: number; day: number; time: number; gold: number; reputation: number;
    buildings: number; citizens: number; adventurers: number; // counts
  }
  export type CommandResult = { ok: true } | { ok: false; error: string };
  export interface Game {
    readonly world: Readonly<World>;
    readonly rng: Rng;
    snapshot(): Snapshot;
    command(name: string, args?: Record<string, unknown>): CommandResult;
  }
  export function createGame(seed: number): Game;

  // src/debug.ts
  export interface DebugHook {
    getState(): Snapshot;
    cmd(name: string, args?: Record<string, unknown>): CommandResult;
  }
  export function createDebugHook(game: Game): DebugHook;
  export function installDebugHook(target: { __hearthcrown?: DebugHook }, game: Game): void;
